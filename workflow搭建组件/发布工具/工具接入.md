# 辅助工具接入

业务 Skill 决定何时调用；工具 Skill 保存所选实现的命令、参数、失败处理和回读方法。先验证实际工具调用，再开始依赖它的任务。不要用一次安装成功推断完整业务已完成。

| 入口 | 必要准备与使用规则 |
|---|---|
| `zotero` | 安装并授权本地 Zotero CLI＋Skill（本机验证使用 `54yyyu/zotero-mcp`）。保持 Zotero 打开，实际读取库及条目后保存确切 key。写前读已有正文，增量分类，写后回读。 |
| `mineru` | 配置本地 MinerU CLI＋Skill与解析模型。本机验证使用 Basic／ONNX／CPU；按实际所需页范围读取并检查截断，关键图式实际查看原页图。工具返回的 locator 与附件版本一起保存。 |
| `obsidian-cli` | 启用 Obsidian 官方 CLI，安装相应工具 Skill。始终明确库和目标路径，不能使用最近活动库推断正式目标。按需加载 `obsidian-markdown`、`json-canvas`。 |
| Undermind MCP | 在 Harness 中连接用户选定账户。02 先发现实际工具名与 schema，再按检索目标调用；已有记录的恢复与新搜索分开。深搜结果不明先查询原任务。 |

具体命令从各自已部署工具 Skill 获取，避免把某台机器的绝对路径、密钥或过期 schema 写入业务规则。业务阶段的原文证据、正文版本、个人判断和保存规则不因工具替换而改变。

Obsidian 大段正文的 IPC 存在环境相关长度限制。遇到通信错误时先检查目标是否已写，再按所用适配器支持的方法保存；不能因退出码为零就标为完成。本机适配器曾用本地载荷文件转发长 eval，未据此宣称官方故障已修复。
