# 留一句写作参考 Skill

先读取 [阶段控制约定](../../../../阶段控制约定.md)。完成本 Skill 后停止等待；另一业务阶段须由用户明确调用目标 Skill 并下令开始，日常读取与保存按支持动作处理。

本文件为发布包执行规则。执行前读取 [参考句约定](../../参考句约定.md)，按其来源、用途、保存与完成规则处理。

1. 接续模式、目录、任务／文献、材料版本、已有候选／原话、实际用途及最新适用规则；必要上下文由 [对齐 Skill](../../../01-对齐当前状态/Skill草稿/paper-align-state/SKILL.md) 取得。直接提供句子也能进入，不要求上游或三笔记齐全。只查回已有条目可按实际正文、位置与原核对范围返回，不重分析或制造版本。
2. 从实际可读原文中聚焦一句，按本次需要可比较多句；优先复用 04／06 定位。默认不为每篇凑句，已读范围无合适内容可无所得，不凭题名、笔记改写或模型记忆生成作者原句。
3. 对照来源核对准确词句、语言、材料版本、真实位置及必要前后文。用户输入、原始摘录、译文、AI 释义分开；无来源保留待核查。可在当前阶段用实际工具核对；确需 [04 Skill](../../../04-原文定位＋提问式阅读/Skill草稿/paper-read-with-questions/SKILL.md) 时保存候选与返回点，等待用户调用及开始命令。
4. 分别说明事实引用或表达借鉴用途、支持意思与条件；目标过强时指出不支持。用户选择、受托挑选与 AI 建议分别保留，转引只记录实际已读来源。已有资料可直接核查；需要 [02 Skill](../../../02-找论文并分层/Skill草稿/paper-find-screen/SKILL.md) 新发现或补搜时保存缺口，等待用户调用并下令开始，不编原始来源。
5. 把实际原句、来源、语境、用途、候选 ID、原话及材料版本交 [更新 Skill](../../../01-对齐当前状态/Skill草稿/paper-update-state/SKILL.md) 保存回读。必要问题先保存再提出，结束本轮等真实回应；已有明确用途不重复确认。依据正文、索引及入口分项结果报告，保存失败不冒充已存。
6. 更新前读实际内容，只改受影响条目；同源同句复用，多用途分别记录，不混合不同论文／版本。只改用途保留原句和定位，暂停保存当前问题与恢复入口。原句核对、用途支持和保存结果分别判断。
7. 保存后报告第七阶段结果并停止等待。正式归档为 [08 Skill](../../../08-归档与关系图/Skill草稿/paper-archive/SKILL.md) 准备真实原句、用途与源版本；文章组织分析为 [06 范例 Skill](../../../06-分类，积累写作范例/Skill草稿/paper-collect-writing-examples/SKILL.md) 准备材料。用户明确调用并下令后才执行相应阶段，不自动扩展或归档。

原句及实际出处在已述范围核对、语境可恢复、用途和支持边界明确，正文／索引回读成功，才报告对应参考句已核对并保存。仅已存待查线索、用途不支持、无合适所得和保存失败分别说明；不把落盘、译文、用户未回应或正式归档等同于结论已核实。
