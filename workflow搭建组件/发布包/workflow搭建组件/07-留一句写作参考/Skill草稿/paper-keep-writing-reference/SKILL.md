# 留一句写作参考 Skill

本文件为已部署执行规则。执行前读取 [参考句约定](../../参考句约定.md)，按其来源、用途、保存与完成规则处理。

1. 接续模式、目录、任务／文献、材料版本、已有候选／原话、实际用途及最新适用规则；必要上下文由 [对齐 Skill](../../../01-对齐当前状态/Skill草稿/paper-align-state/SKILL.md) 取得。直接提供句子也能进入，不要求上游或三笔记齐全。只查回已有条目可按实际正文、位置与原核对范围返回，不重分析或制造版本。
2. 从实际可读原文中聚焦一句，按本次需要可比较多句；优先复用 04／06 定位。默认不为每篇凑句，已读范围无合适内容可无所得，不凭题名、笔记改写或模型记忆生成作者原句。
3. 对照来源核对准确词句、原文语言、文献／附件版本、真实位置及必要前后文。用户输入、原始摘录、译文、AI 释义分开；只有句子而无可对照来源时保留待核查，不称逐字／出处已核实。借用 [04 Skill](../../../04-原文定位＋提问式阅读/Skill草稿/paper-read-with-questions/SKILL.md) 时，仅定位／核对原句用资料核查，用户需要理解时用局部陪读；携候选 ID 和返回点，处理后回到本句用途判断，不转入 05。
4. 分别说明事实引用或表达借鉴用途、能支撑的意思与条件，目标过强时指出不支持，不改原句迎合结论。用户选择、受托挑选与 AI 建议分别保留；转引只记录实际已读来源。需发现／补搜原研究时交 [02 Skill](../../../02-找论文并分层/Skill草稿/paper-find-screen/SKILL.md) 真实使用 Undermind MCP，已有可定位资料按实际工具读取并交 04 核查，不编原始来源。
5. 把实际原句、来源、语境、用途、候选 ID、原话及材料版本交 [更新 Skill](../../../01-对齐当前状态/Skill草稿/paper-update-state/SKILL.md) 保存回读。必要问题先保存再提出，结束本轮等真实回应；已有明确用途不重复确认。依据正文、索引及入口分项结果报告，保存失败不冒充已存。
6. 更新前读实际内容，只改受影响条目；同源同句复用，多用途分别记录，不混合不同论文／版本。只改用途保留原句和定位，暂停保存当前问题与恢复入口。原句核对、用途支持和保存结果分别判断。
7. 正式归档按既有机制固定源版本及快照，交 [08 Skill](../../../08-归档与关系图/Skill草稿/paper-archive/SKILL.md) 写入并回读，01、08 不扩充。若要文章组织范例，按用户需求交 [06 范例 Skill](../../../06-分类，积累写作范例/Skill草稿/paper-collect-writing-examples/SKILL.md)，留句不自动扩成写法分析。

原句及实际出处在已述范围核对、语境可恢复、用途和支持边界明确，正文／索引回读成功，才报告对应参考句已核对并保存。仅已存待查线索、用途不支持、无合适所得和保存失败分别说明；不把落盘、译文、用户未回应或正式归档等同于结论已核实。
