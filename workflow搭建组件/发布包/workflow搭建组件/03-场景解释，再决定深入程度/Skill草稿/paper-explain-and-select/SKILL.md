# 场景解释，再决定深入程度 Skill

本文件为已部署执行规则。开始执行时读取 [解释与选择约定](../../解释与选择约定.md)，按其中的证据、类比边界、选择字段和交接要求处理。

## 必须保留的边界

- 关于论文的解释须基于实际可读资料。题名或模型记忆不足以构成该论文方法的依据；只有摘要时限定范围，未知细节保留待核查。
- 场景类比回到真实问题、模块、信息流和输出，说明不对应之处。教学船舶场景不代表作者做过船舶验证，也不证明方法可以直接迁移。
- 用户决定阅读深度。AI 推荐、用户兴趣、已明确选择和已掌握范围分开；未回复或含糊表达不触发自动精读。

## 执行

1. 使用已有的模式、任务、论文／材料版本、基础、目标和工作区入口，核对最新适用规则与临时要求；必要上下文缺失时由 [对齐 Skill](../../../01-对齐当前状态/Skill草稿/paper-align-state/SKILL.md) 取得。用户已明确深度时可缩短或跳过讲解，仍保存其决定。
2. 从真实摘要、方法片段、图或代码提取当前可支持的问题、输入、输出和关键机制，并记录出处。需要更多同一论文资料时用已接读取工具或现有文件；需要发现新论文时交 [02 Skill](../../../02-找论文并分层/Skill草稿/paper-find-screen/SKILL.md) 通过 Undermind MCP 搜索，不用记忆补候选。
3. 用贴近用户的生活或船舶海洋场景讲清主线，标明场景性质，再把对象、动作、关系与结果映射回有依据的真实模块，说明类比边界。用户不需要类比时用其熟悉概念直接解释。
4. 解释有实质正文后，连同当前建议和待决定状态先交 [更新 Skill](../../../01-对齐当前状态/Skill草稿/paper-update-state/SKILL.md) 保存并回读，再等待反馈。恢复讲解读取已保存版本，按当前问题接续，不从空白重讲。
5. 根据反馈纠偏或补必要背景，提出与目标相关的建议，取得明确选择或保留待决定。实际确认范围与 AI 讲过分开；用户创新／不足仍由其本人提出。无需固定测验，已选精读但缺材料时保留选择和待补项。
6. 将本次原话、纠偏、疑问、决定和同一评估的增量交更新 Skill 保存，后续要再次等待时也先保存本轮新内容。只由它写工作区，回读成功才能称已保存；明确选择尚未保存时不得宣称决策记录已完成。
7. 按约定中的选择分流：明确继续原文阅读时，携定位、真实理解依据、疑问、规则与材料版本交 [04 Skill](../../../04-原文定位＋提问式阅读/Skill草稿/paper-read-with-questions/SKILL.md)；筛读已足够可结束，需分类时交 [06 分类 Skill](../../../06-分类，积累写作范例/Skill草稿/paper-classify-content/SKILL.md)，需归档时交 [08 Skill](../../../08-归档与关系图/Skill草稿/paper-archive/SKILL.md)。暂缓／不纳入保存后结束，复现候选仅记录后续意图；实际复现检查按明确需求分配资料核查或阅读，不自动运行实验。未决定则留在 03，暂停保留续读入口；下游未部署／不可用时只准备交接。

## 完成与停留

解释范围、来源和类比边界明确，用户实际选择已保存、下一步或缺项清楚时，选读决策才算完成。解释已保存但用户未选，只能报告待选择；用户主动跳过时记录跳过和指定深度，不虚构讲解完成。保存失败、资料不足和未决定分别说明。
