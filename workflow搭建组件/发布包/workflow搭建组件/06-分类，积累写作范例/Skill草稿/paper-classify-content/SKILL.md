# 论文内容分类 Skill

先读取 [阶段控制约定](../../../../阶段控制约定.md)。完成本 Skill 后停止等待；另一业务阶段须由用户明确调用目标 Skill 并下令开始，日常读取与保存按支持动作处理。

本文件为发布包执行规则。执行前读取 [内容分类约定](../../内容分类约定.md) 和 [共享约定](../../共享约定.md)，写作范例未要求时不加载其分支。

1. 接续模式、目录、任务／文献、资料版本、实际分类需求与最新适用规则；取回已有分类、上游事实和位置，必要上下文交 [对齐 Skill](../../../01-对齐当前状态/Skill草稿/paper-align-state/SKILL.md)。不要求三笔记齐全或重跑上游。
2. 从实际材料分别核对论文研究问题和采用方法，按证据范围归类；摘要只支持摘要范围，用户迁移设想不当论文实际任务，不用题名／记忆补核实事实。
3. 按当前类别定义与别名复用，各轴允许多类。确有区别再提出新类，近义但含义不同不擅自合并；保留已有分类和无关标签，普通单篇任务不重排全库。
4. 提交类别、理由、真实来源位置、核对范围及当前文献增量。局部事实可用实际工具在当前阶段核查；需要启动 [04 Skill](../../../04-原文定位＋提问式阅读/Skill草稿/paper-read-with-questions/SKILL.md) 或 [02 Skill](../../../02-找论文并分层/Skill草稿/paper-find-screen/SKILL.md) 时只保存缺口、当前问题与返回点，等待用户明确调用及开始命令。
5. 将实际正文、来源、材料 ID／版本与下一步交 [更新 Skill](../../../01-对齐当前状态/Skill草稿/paper-update-state/SKILL.md) 保存回读。关键歧义先保存候选和问题，再提问并结束本轮，等真实回应；不逐标签机械确认，不以保存成功代替事实核实。
6. 按分项回读结果报告本次内容分类结果，停止等待。为 [08 Skill](../../../08-归档与关系图/Skill草稿/paper-archive/SKILL.md) 或 [写作范例 Skill](../paper-collect-writing-examples/SKILL.md) 准备材料；即使两项都需要，也分别等待用户调用并下令开始。同类标签不自动生成论文关系。

本次各轴的结果、证据范围、未知项及增量清楚，正文和索引回读成功才能称对应分类已保存。关键证据／类别歧义未解时保留暂定或待核查；不要求写作范例产物，也不宣称已正式归档。
