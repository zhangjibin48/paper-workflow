# 实验代码的 draw.io 全流程图

仅在 04 主流程建立或更新代码图时读取。本文件规定图与代码的对应、交付和核对；学习与等待见 [阅读与提问约定](阅读与提问约定.md)。

## 从代码确定流程

先取得可读仓库／本地代码，记录实际版本与官方／第三方来源。按 README 的实验命令、脚本入口、配置解析、数据构造、模型构造及调用逐步追踪，核对真正启用的实现和参数覆盖。README 与文件名是定位线索，图中的连接以实际实现为依据。

覆盖选定实验从入口到结果的全程。训练存在时核对数据划分／处理、批次输入、模型计算、损失、梯度与更新、循环、验证、权重保存等实际环节；推理存在时核对配置、权重加载、输入处理、模型计算、后处理及结果／评估。按代码实际机制取舍，不强套所有论文都含训练或梯度更新的模板；标签、训练增强或损失不得混入实际不使用它们的推理链。

分支、汇合、迭代和关键数据形状在影响理解处画清；训练／推理共享模块沿用稳定节点标识或明确引用，权重等跨流程产物画出来源与用途。核心创新组件醒目标记，图例说明样式含义。

主图展示完整实验链，复杂组件可用子图展开内部结构并从主图回链；主图与子图共同覆盖必要实现。与核心计算无关的通用样板可归并。每个实质节点能回到实际文件／类／函数及必要论文位置；来源映射保存在阅读记录，图面保持易读。

## 可编辑源文件与展示

使用实际可用的 draw.io 工具、桌面应用／CLI，或生成可被 draw.io 打开的原生 `.drawio` 文件。工具入口与导出参数先读取实际帮助／工具 schema，避免把某台机器路径或猜测的参数写为通用命令。没有专用工具 Skill 时可直接生成原生图文件，再用已安装 draw.io 打开、导出和核对。

- 有训练和推理时分别建命名页或文件；总览、训练、推理、必要组件子图清楚区分。
- 保存可编辑源文件，并为实际使用的图页导出可直接展示的 PNG 或 SVG 预览；多页图逐页核对和展示，不只给第一页截图或不可见的文件路径。
- 原生文件保留真实节点、连线和分组，不能把一张不可编辑位图塞进空白画布当作可编辑流程图。直接生成时可使用未压缩 `mxfile / diagram / mxGraphModel` XML，文本及属性按 XML 正确转义。
- 生成中间文件可用工具临时位置；交现有更新 Skill 保存持久副本、预览和版本映射。更新既有图前先读取，保留用户手改、无关页和布局，只改受影响部分。

无法导出或打开时保存真实源文件及错误，说明“图已生成、展示待核对”，先修复可读展示。没有 draw.io 能力时保留待配置状态；不静默改用 Mermaid 或只给文字清单并宣称完成用户要求。

## 核对与完成

依次核对：文件可解析、各页节点 ID 与连线端点有效；从入口沿边能走到真实输出，关键分支和循环与代码一致；训练／推理及核心创新节点均已覆盖；图页能在 draw.io 打开或导出；实际查看预览，文字清楚、箭头方向正确、没有遮挡截断。

XML 检查、来源映射与视觉核对分别记录。可绘制不等于路径已证实，图画完不等于用户已经理解。未取得的代码和未确认的动态行为明确标为缺口／静态推导，不以猜测连线补齐“完整图”。
