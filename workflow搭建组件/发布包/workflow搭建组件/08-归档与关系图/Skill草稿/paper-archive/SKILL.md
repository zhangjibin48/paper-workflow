# 归档与关系图 Skill

先读取 [阶段控制约定](../../../../阶段控制约定.md)。完成本 Skill 后停止等待；另一业务阶段须由用户明确调用目标 Skill 并下令开始，日常读取与保存按支持动作处理。

本文件为发布包执行规则。执行前读取 [归档约定](../../归档约定.md)；向更新 Skill 交接时读取 [状态约定](../../../01-对齐当前状态/状态约定.md) 中的归档回执要求。

处理选文评估时读取 [选文记录约定](../../选文记录约定.md)；独立启动也按 [行为规则约定](../../../01-对齐当前状态/行为规则约定.md) 读取最新启用规则。输入工作区按 [临时成果约定](../../../01-对齐当前状态/临时成果约定.md) 取回。

## 执行

1. 使用已有模式、目标、材料版本与目录，加载最新适用规则。审阅看样稿，试跑用隔离副本；正式目标按本次范围提供，纯本地筛选归档不强制连接 Zotero／Obsidian。
2. 从工作区索引取回原话、草稿与选文正文，确认源 ID／版本和本次范围。未落盘成果先交 [paper-update-state](../../../01-对齐当前状态/Skill草稿/paper-update-state/SKILL.md) 保存，提交前让它固定版本快照并回读。暂停时由它保存全部新正文与进度，无需正式归档。
3. 涉及 Zotero 时按库标识和条目 key 核对论文，复用已有对象；多候选有歧义先解决身份。不入库候选按评估标识写本地筛选档案，保留全部字段。
4. 按选文约定保存分区体系／年份、代码／数据链接、复杂度、复现条件、筛选结果／理由与来源，回读正文后更新选文索引。按归档约定保存适用三笔记、附件和分类；个人来源清楚，笔记二关联已存在的笔记一，缺项按原因记录。
5. 增量更新分类和 Obsidian 导航、写作范例与引用入口。保持 Zotero 为三笔记主库，入口回链同一篇论文。
6. 有本次适用关系时更新 Canvas。沿革要有原文／代码依据，相似关系说明机制或问题及差异；候选关系先留候选。复用稳定 ID，保留无关内容与已有布局。
7. 每项写后回读，及时记入归档记录。工具成功但未确认记“待核对”；部分失败保留成功项和重试入口。重试先查询实际对象再补增量，避免重复创建。
8. 返回源材料 ID／版本、正式目标、选文索引结果、真实回执与未完成项，交更新 Skill 关联工作区并保存当前任务。归档旧版不能标记新版完成，不自动清理原话和草稿。回执或状态保存失败分别说明。报告第八阶段结果后停止等待，不自行启动下一篇或新任务。

## 完成标准

本次适用项有逐项结果；选文字段和出处能从正式 note／筛选档案回读，三笔记与个人判断来源正确，关系有依据。回执关联确切源版本，未归档内容仍可恢复；归档记录、索引及状态更新分别报告真实结果。
