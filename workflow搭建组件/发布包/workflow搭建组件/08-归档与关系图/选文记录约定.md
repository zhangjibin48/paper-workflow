# 选文信息的保存、归档与回读

开始与收尾先遵守 [阶段控制约定](../../阶段控制约定.md)。本文件中的跨业务阶段交接仅准备材料，用户明确调用目标 Skill 并下令开始后才执行；日常读取与保存仍返回当前阶段。

选文记录覆盖原流程 02 的候选评估，以及 03—07 中补充的判断。它是独立的辅助记录，不混入三份阅读笔记。当前只制定字段和保存规则，尚未检索或核验任何真实论文信息。

## 保存位置与负责方

| 阶段／对象 | 明确位置 | 维护者与后续入口 |
|---|---|---|
| 正在筛选或尚未归档 | `状态目录/任务成果/任务标识/文献/文献标识/选文记录/评估标识.md` | 02 等业务步骤提供内容，更新 Skill 保存；对齐从工作区索引找回 |
| 已入 Zotero 或本次确定入库的论文 | 同一论文下独立的“选文记录”附属笔记 | 08 创建或复用对应 note key；三笔记仍保持各自独立 |
| 本次不入库的候选，包括暂缓或不纳入的论文 | `归档记录目录/筛选档案/评估标识.md` | 08 保存完整字段并回读；不要求为了保存筛选理由把所有淘汰候选导入 Zotero |
| 全部正式评估的查找入口 | `归档记录目录/选文索引.md` | 08 维护评估标识、任务、文献映射、版本、正式位置和简短结果；续读和归档重试据此取回正文 |

同一篇论文可以因任务目标不同有多次评估。评估标识绑定一次具体目标与判断，文献标识绑定论文；两者分别保存。Zotero 的“选文记录”按评估标识分段保留，不以最新结论覆盖其他任务的原判断。

不入库候选后来决定入库时，08 将相应版本写入 Zotero 并回读，更新选文索引的正式位置；原本地版本保留为快照和转向引用，正式可编辑位置只有一个。

## 每份评估应保留的固定字段

未知可以明确记为待核对，不要求所有字段查齐才能筛读。每项事实保留来源链接或原文位置、记录／核对日期、已知与未知状态；AI 估计另标，不能改写为作者报告。

| 字段组 | 必须能表达的信息 |
|---|---|
| 评估身份与目标 | 评估标识、任务标识、文献标识、记录版本、评估日期；当前兴趣／问题、阅读用途与深度 |
| 论文身份 | 题名、作者、发表年份、期刊／会议、DOI／正式链接；已入库时补库标识与论文 key |
| 刊会层次、分区口径与年份 | 分区／评级体系名称、采用的版本或年份、学科／大类小类口径、结果、出处及核对日期；论文发表年份单列，不能代替分区年份；不适用时写明原因 |
| 代码 | 代码／仓库链接、作者官方或第三方来源、相关版本／commit（已知时）、可访问与已验证状态；“作者声称公开”“找到链接”“运行通过”分开 |
| 数据 | 数据名称、版本、公开链接或获取条件、预处理和关键依赖；未公开、未找到与未核对分别记录 |
| 复杂度与资源 | 方法规模、参数量／理论复杂度、训练和推理资源、显存／时间等已报告信息及位置；缺项保留未知，AI 估计注明依据与不确定性 |
| 复现条件 | 所需代码、数据、环境／框架、关键参数、训练权重与硬件等现有条件；用户实际算力的可行性依据、已实际验证部分和仍缺的条件；未运行不能写成已复现 |
| 筛选结果和理由 | 纳入筛读／精读／复现候选／暂缓／不纳入等实际决定，理由、相关问题／方法、保留或放弃原因、待核查项和下一步 |
| 判断来源 | 区分 AI 推荐、用户选择和依据；用户尚未决定时保留候选，不冒充用户已选 |

发表时间和刊会层次是选文参考，经典论文、方法演变需要及用户兴趣可以成为保留理由。筛选结论应关联本次目标，不只保存一个分数或“相关／不相关”标签。

## 传到 08 的方式

1. 业务步骤形成或补充评估时，交更新 Skill 保存完整评估正文，写入工作区索引中的材料 ID、文献、版本、实际路径与未核对项。
2. 暂停或切换时，该评估随工作区一起保存。对齐先读索引，再按任务与论文取回相应正文，不要求用户重述代码、分区和筛选理由。
3. 08 从已保存的具体版本读取字段和出处，确定本次入库选择及正式位置；不从“已做筛选”这种摘要重新猜测内容。
4. 对已入库论文写入或更新“选文记录”note；对不入库候选写入本地筛选档案。只保存本地筛选档案的归档任务，不依赖 Zotero 或 Obsidian 已接通。
5. 回读正式对象，核对评估标识、任务／论文、版本以及各字段和来源，尤其是分区口径与年份、代码／数据链接、复杂度、复现条件、筛选结论和理由。未知状态必须保留。
6. 正式正文回读成功后，更新选文索引，再形成回执，包含源材料与版本、note key 或实际文件路径、逐项结果。索引保存失败则报告入口待修复，返回可直接恢复的正文位置。

更新 Skill 收到回执后标记对应草稿版本及正式位置；新版本仍待归档。需要重新核查时通过选文索引回读正文与原始来源，不把上次结果当成永远有效。
