# 找论文并分层 Skill

本文件为已部署执行规则。执行前读取 [Undermind MCP 调用约定](../../UndermindMCP调用约定.md)，这是本阶段必需的工具路径和成功条件。

## 必须遵守

- 新找文／补搜按任务实际调用 Undermind MCP：使用 `search_papers` 的全局、参考文献或引文范围，或选择 `launch_deep_search`；工具名和参数以真实目录及 schema 为准。引用链检索符合本次目标时可独立完成，不要求追加全局搜索或深搜。
- 查看帮助、列工作区或单篇元数据核对都不能替代一轮新搜索。保存真实调用与返回，并让候选能回到对应结果。
- MCP 不可用、未授权、调用失败或结果未取得时，报告真实状态，外部检索保持未完成；不以模型记忆、普通网页搜索或未核对清单静默顶替。

## 执行

1. 读取调用方提供的模式、任务、目标、相关基础／约束、最新规则和工作区入口；缺失必要上下文时按 [对齐 Skill](../../../01-对齐当前状态/Skill草稿/paper-align-state/SKILL.md) 取得。已有信息直接用，探索方向不要求先锁定细分课题。
2. 区分新检索、恢复检索与指定候选核对。正式执行确认真实 MCP 工具、账户／工作区和必要 schema；设计审阅不发起真实研究，模拟结果不作真实来源。
3. 新检索按目标选择范围：方向探索或广泛找文可全局检索／深搜，给定论文查前作走参考文献，找后续研究走引文。引用链先核对种子论文身份、方向与版本。交 [更新 Skill](../../../01-对齐当前状态/Skill草稿/paper-update-state/SKILL.md) 保存意图，再调用真实搜索工具。恢复先查原记录，单纯身份核对与引用链搜索分别标注。
4. 收到返回立即交更新 Skill 保存实际工具、参数、范围、内容／位置及状态；引用链另存种子论文、方向和多跳路径。运行中、返回范围未取全或提交结果不明时保留恢复入口，不能冒称全部完成。
5. 从真实结果建立候选并核对身份、版本和出处。引用链候选保留来自哪个种子的参考文献／引文结果；引用关系不直接写成改进或继承，具体方法关系需原文／代码依据。模型线索与 Zotero 既有材料仍分别标注。
6. 按 [选文记录约定](../../../08-归档与关系图/选文记录约定.md) 补事实和判断。摘要与全文的证据范围分清，未知和估计保留；经典价值、阅读价值和复现条件分别考虑，不能仅按年份、分区或缺代码机械剔除。
7. 给出少量有理由的筛读／精读／复现候选建议。用户决定另记，不能把未回复当作已选择。需要场景解释的候选交 [03 Skill](../../../03-场景解释，再决定深入程度/Skill草稿/paper-explain-and-select/SKILL.md)，不提前代做三笔记的个人判断。
8. 将检索、调用返回和评估正文交更新 Skill 保存并回读；材料结构按 [临时成果约定](../../../01-对齐当前状态/临时成果约定.md)。向下一步交接真实论文定位、材料版本、推荐理由与未知项；适合正式归档时交 08，不在此直接建立另一套主库。

## 完成标准

完成状态与任务目标、实际范围和执行分支一致：全局、参考文献、引文或深搜取得真实返回，完成本次约定范围即可；引用链可以独立完成前作／后续研究找文，无需额外全局搜索。单篇元数据核对不冒充发现检索。候选与链路可追溯，评估及执行状态已保存；具体改进关系尚未核实则保留待核查。失败、无结果及部分保存分别说明。
