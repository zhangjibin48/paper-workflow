# 更新 Skill

先读取 [阶段控制约定](../../../../阶段控制约定.md)。完成本 Skill 后停止等待；另一业务阶段须由用户明确调用目标 Skill 并下令开始，日常读取与保存按支持动作处理。

本文件为发布包执行规则。执行前读取 [共享状态约定](../../状态约定.md)，以其字段、写入归属和保存规则为准。

有原话、草稿、选文或写作素材时读取 [临时成果约定](../../临时成果约定.md)；处理长期纠正时读取 [行为规则约定](../../行为规则约定.md)；保存选文评估时按 [选文记录约定](../../../08-归档与关系图/选文记录约定.md) 保留固定字段及出处。

## 执行

1. 确认模式、目录、触发事件及变更依据；涉及阅读时核对任务标识，全局规则更新无需创建阅读任务。已有路径直接用，审阅保持样稿不变，试跑使用独立副本。
2. 写前重读实际记录和受影响材料，对照任务、文献、材料及版本决定增量，保留原话、未解问题和未完成项；无变化返回“未变化”。
3. 根据事件处理：
   - **建档／背景纠正**：只写有来源的用户背景和明确纠正，未知项留未知。
   - **重要进展**：更新目标、原文位置、用户已确认的理解、疑问与下一步。AI 讲解过的内容保持为待验证，除非用户已复述或确认。
   - **成果暂存**：保存用户相关原句及三笔记草稿、选文评估、写作素材等实际正文；标注来源和材料版本。先回读正文，再更新索引和当前任务入口。
   - **行为纠正**：明确长期要求写入行为规则，保留来源、适用范围和例外；一次性要求写当前任务临时要求并标明范围，续读仍可取回，不自动升级为长期规则。保存后返回变更供本轮立即应用。
   - **切换／恢复**：先核对旧论文材料、工作区索引及必要任务快照，再更换活跃入口；原工作区保留并返回恢复路径，失败时不以新任务覆盖旧入口。
   - **归档准备**：将本批源材料和版本保存为固定提交快照并回读，把真实路径交给 08；此时只表示材料可提交，不表示已经正式归档。
   - **归档结果**：按源材料 ID／版本核对 08 回执，更新索引的正式目标与当前任务摘要。保留未归档新版、原话及失败项，不自动删除草稿；正式详细记录由 08 维护。
   - **会话收尾**：保存最后位置、疑问、下一步，以及本轮新增的原话和全部未归档成果。用户暂停时保留任务未完成；目标达成和归档状态分别判断。
4. 对实际修改的文件分别递增版本，按三个工具阶段保存：先完成原话／正文的所有改动（包括补 ID、来源和保存结果），等待这些文件的实际回读返回；再写索引并等待其回读返回；最后更新当前任务入口并回读。正文修改与索引写入不能放在同一工具批次，也不能把“已发出回读”当作“回读成功”。若回读后再改正文，重新从正文回读阶段开始。核对正文、索引和当前入口均一致；只保存摘要或只有索引不算成果已保存。部分失败逐项说明。
5. 返回实际路径、版本、规则变更、成功项及剩余事项。失败时可提供待保存正文，但不能把回复中的正文当成已经落盘，也不能承诺规则下次已能加载。

## 完成标准

已保存的原话、正文、索引、状态和规则能回读验证，并能定位未归档材料。失败／冲突项与未保存规则清楚保留，旧版归档不冒充新版完成。作为支持动作结束后只返回当前阶段；独立保存完成后停止等待，不自动启动归档或其他业务阶段。
