# 对齐 Skill

本文件为已部署执行规则。执行前读取 [共享状态约定](../../状态约定.md)，按其中的字段与目录区分审阅、独立副本试跑和实际阅读。

## 执行

1. 使用调用入口已有的运行模式和状态目录。只有运行需要且确实缺失时才补充。设计讨论可以读样稿，保持实际阅读记录不变。
2. 读取学习档案、当前任务和最新启用行为规则，按 [行为规则约定](../../行为规则约定.md) 加载相关条目。首次开始沿用既有资料；恢复历史任务仍使用最新规则。资料缺失交给更新 Skill 建立，不能声称已加载不存在的规则。
3. 当前任务或历史快照有工作区索引时，按 [临时成果约定](../../临时成果约定.md) 读取相关论文的原话、草稿、选文评估和写作素材，核对正文路径及版本。缺失材料报明缺口，不用摘要编造内容。
4. 结合本轮要求确定继续、调整、切换或恢复哪项任务。方向探索可保持宽泛；单篇阅读需可定位资料。只询问影响下一步的缺项和冲突，已有背景和本轮已给目标直接使用。
5. 有建档、纠正、规则变化、目标变化或切换时，交 [paper-update-state](../paper-update-state/SKILL.md) 保存，规则明确长期时直接处理；不自行写共享记录或替调用方声称已保存。
6. 交接目标、必要背景、定位、疑问、下一步、已加载规则以及相关材料路径／版本。更新失败说明未保存部分；不依赖该写入的阅读工作可以继续，保留失败状态。

## 完成标准

本次目标与下一步清楚；相关未归档正文能按索引取回，最新适用行为规则已交接。关键缺项和未保存变化明确说明。对齐后由当前业务任务继续，无需用户手动切换 Skill。
